# BRIGADE — 厨房業務アプリ（独立版）

飲食店の料理人向けの業務改善アプリです。在庫・棚卸し・発注・検品、レシピ・原価・仕込みリスト、シフト・業務連絡・衛生記録（HACCP）、売上・ロス分析・改善ボード、自分専用のタスク（時間割）とクイックメモを1つにまとめています。

Claude や外部サーバーには依存しません。データはすべて**利用者の端末の中（ブラウザの保存領域 IndexedDB）**に保存され、どこにも送信されません。

## 使い方

| 端末 | ホーム画面に追加する方法 |
|---|---|
| iPhone / iPad | Safari で開く → 下の「共有」ボタン → 「ホーム画面に追加」 |
| Android | Chrome で開く → 表示される「追加する」ボタン（または右上メニュー → 「アプリをインストール」） |
| パソコン | Chrome / Edge のアドレスバー右端の「インストール」アイコン |

- 追加すると全画面のアプリとして起動し、一度開けば電波がなくても使えます。
- 初回起動時に「サンプルで試す」を選ぶと、（例）付きのサンプルデータで操作を試せます。

## データの保存とバックアップ

| 項目 | 内容 |
|---|---|
| 保存場所 | その端末のアプリ内（IndexedDB）。端末ごとに別々のデータです |
| 消えにくくする | ホーム画面に追加して使う（iPhone はブラウザのまま長期間使わないと消されることがあります） |
| バックアップ | 右上の歯車 →「バックアップを書き出す」で1つのファイル（.json）に保存。週1回をおすすめします |
| 機種変更・別端末へ | 新しい端末で開き、歯車 →「バックアップから読み込む」 |
| 全部消す | 歯車 →「すべてのデータを消す」 |

## フォルダの中身

| ファイル | 役割 |
|---|---|
| `index.html` | 画面の土台（デザイン・ホーム画面追加の案内） |
| `core.js` | 共通の仕組み（保存・画面切替・メモ・今日モード・バックアップ） |
| `mod-inventory.js` | 在庫・棚卸し・発注・検品・ロス |
| `mod-recipe.js` | レシピ・原価・仕込みリスト |
| `mod-shift.js` | シフト・業務連絡・衛生記録 |
| `mod-sales.js` | ホーム・売上・分析・改善ボード |
| `mod-mypage.js` | マイページ（タスク・時間割） |
| `manifest.webmanifest` | ホーム画面に追加したときの名前・アイコン |
| `sw.js` | オフライン起動用 |
| `sample.json` | サンプルデータ |
| `icons/` | アプリアイコン |

このフォルダを丸ごと https のサーバーに置くだけで動きます（GitHub Pages / Netlify / Cloudflare Pages など）。

## パソコンで試す

```
python3 -m http.server 8000
```

ブラウザで `http://localhost:8000` を開きます（ファイルを直接ダブルクリックするとオフライン機能が動きません）。
